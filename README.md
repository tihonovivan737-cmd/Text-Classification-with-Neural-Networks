# Text Classification with Neural Networks

Проект сравнивает несколько нейросетевых архитектур для классификации текстов новостей по категориям:

- `Transformer`
- `MLP`
- `LSTM`
- `GRU`

Скрипт обучает выбранную модель, оценивает качество на тестовой выборке и сохраняет артефакты обучения.

## Возможности

- предобработка текстов и токенизация;
- построение словаря на основе обучающего корпуса;
- кодирование меток классов;
- обучение одной из четырёх моделей на выбор;
- расчёт точности на обучающей и тестовой выборках;
- опциональный базовый анализ данных перед обучением;
- сохранение модели, словаря, логов и служебных файлов.

## Стек


## Подготовка данных

Скрипт ожидает файл `data.txt` в корне проекта.

Формат файла: одна запись на строку, где текст и метка разделены последней запятой.

Пример:

```text
Новый спутник вышел на орбиту,science
Команда выиграла финальный матч,sport
Курс акций резко вырос,business
Международные переговоры завершились,world
```

Важно:

- файл должен быть сохранён в кодировке `UTF-8`;
- если в тексте встречаются запятые, скрипт всё равно корректно выделит метку, потому что делит строку по последней запятой;
- категории должны быть записаны единообразно во всём датасете.

## Запуск

```powershell
python text_classification.py
```

Во время выполнения скрипт:

1. загрузит данные из `data.txt`;
2. предложит выполнить анализ данных;
3. попросит выбрать модель:
   - `1` — Transformer
   - `2` — MLP
   - `3` — LSTM
   - `4` — GRU
4. запросит количество эпох обучения;
5. выведет метрики по эпохам в консоль.

## Что сохраняется после обучения

После запуска создаётся папка `MLP`, в которую сохраняются:

- `training_log.txt` — лог обучения по эпохам;
- `model.pth` — веса обученной модели;
- `datasets.pth` — сохранённые train/test датасеты;
- `vocab.pth` — словарь токенов;
- `label_encoder.pth` — кодировщик меток классов.

## Текущие особенности проекта

- Имя выходной папки сейчас всегда равно `MLP`, даже если выбрана другая модель.
- Скрипт работает в интерактивном режиме через `input()`.
- При наличии CUDA обучение автоматически будет запущено на GPU.

## Результаты из текущего описания проекта

По имеющемуся описанию в проекте:

- `GRU` показала лучшее соотношение точности и скорости обучения;
- `Transformer` дал близкое качество, но требует больше ресурсов;
- `LSTM` показала немного меньшую точность;
- `MLP` сильнее подвержена переобучению.
